## Windows VPS 贵在哪：授权、内存、硬盘三道坎

Windows VPS 的价格里有一块和性能完全无关的成本：授权。Linux 发行版免费，Windows Server 按月收费。这个差价会直接体现在零售价上：Linux VPS 常见 5 美元/月起，Windows VPS 普遍落在 10 美元/月这一档。

更麻烦的是收费方式不统一。有的商家把授权打包进月费，报价即总价；有的在套餐价之外单独加收 10–20 美元/月的授权费。所以看到两台配置相近的机器价格差一倍，先别急着判断贵的那台不合理，先看它的报价里含不含授权、含的是哪个版本。

第二道坎是内存。Windows Server 本身比主流 Linux 发行版吃资源，2GB 是能用的底线。1GB 的机器装完系统只剩几百兆可用，远程桌面连上去点两下就开始换页，这种配置买回来只会变成一台能开机但不能用的机器。

第三道坎是硬盘。系统装完就占掉十几到二十几 GB，标称 20GB 的盘留给软件的空间不多，30GB 以上才谈得上从容。这一条在后面的套餐表里会直接影响选型，先记住。

## RDP 怎么连：五分钟能搞定的部分

Windows 连 Windows VPS，系统自带客户端，不用装任何东西。任务栏搜索“远程桌面连接”，或者按 Win+R 输入 `mstsc` 回车；在“计算机”一栏填 IP，端口不是默认 3389 的话写成 `IP:端口`，例如 `123.456.789.0:1234`；用户名一般是 `Administrator`，密码在开通邮件或控制面板里。

Mac 用微软官方的 Microsoft Remote Desktop，App Store 免费下载，添加连接时 PC name 一栏同样支持 `IP:端口` 格式。iOS 和 Android 也有同名官方应用，临时看状态够用。

连不上时按顺序排查三件事：IP 和端口有没有填错、防火墙有没有封 3389、在商家控制面板重启一次机器。如果 RDP 服务本身没开，需要先用 VNC 进系统，在“此电脑 → 属性 → 远程设置”里勾选允许远程连接，并确认防火墙的 3389 入站规则是放行的。

画面卡顿通常是两个原因：机房太远导致延迟高，或者远程桌面的画质设置太高。在“显示”选项卡降低颜色深度，在“体验”选项卡关掉壁纸和视觉特效，流畅度会明显改善。如果是延迟本身的问题，调设置没用，得换节点位置。

## 下单前常问的几个问题

**Windows 授权要另外买吗？**

LisaHost 的套餐页没有单列授权费，报价看起来是含系统的总价。但官网也没有明确写“含正版授权”和具体版本号，所以下单前确认一遍更保险，尤其是你需要特定版本（比如必须 2019 或 2022）的时候。

**2GB 内存够跑 Windows 吗？**

够跑，不够富裕。系统本身占掉一部分，剩下的留给应用。单人远程办公、开浏览器、挂几个常驻小工具没问题；装数据库、开多用户会话、跑编译，就得往 4G 走。

**选新加坡还是别的节点？**

看你的使用地。人在大陆想要直连低延迟，新加坡这条线不合适，官网自己建议走香港或日本中转；业务本身面向东南亚，或者你本来就有中转方案，这条线的新加坡原生 IP 就是它的价值所在。

**月付还是年付？**

只有确定长期用、且不需要 Windows 的情况下，年付版（466 元/年）才划算。要跑 Windows，年付版配置不够，只能月付从进阶版起步。不确定就先月付一个月，48 小时内还能退。

**能升级配置吗？**

表里六档是独立产品，不是同一台机器加钱解锁。要换档位，按对应套餐重新开通，数据迁移需要自己处理，这一点下单前要有预期。

**支持什么付款方式？**

官网页面没有集中列出支付渠道，结账页会显示可用选项。国内用户通常关心支付宝，建议在购物车页面直接确认。
